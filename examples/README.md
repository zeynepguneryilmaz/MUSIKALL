# MUSIKALL Example Datasets

This directory contains the input files and reference outputs for the three case studies reported in the MUSIKALL manuscript: β2-adrenergic receptor (β2AR), GAPDH, and the ribosome termination complex.

The example datasets are provided to facilitate reproducibility and to allow users to reproduce the analyses using the same structural inputs, residue definitions, and analysis parameters used in the manuscript.

## Common Analysis Parameters

Unless otherwise stated, the following parameters were used for all three case studies:

- **Residue interaction network cutoff (R):** `4.5 Å`
- **Number of shortest paths (k):** `20`

---

## 1. β2-Adrenergic Receptor (β2AR)

The β2AR structures were structurally aligned before analysis. For the alignment step, **2RH1 was selected as the reference structure**.

The following residue groups were supplied to MUSIKALL:

- **AS:** `A,203,207,113,312`
- **AL:** `A,79,121,282`
- **GPC:** `A,131,219,272,326`


The corresponding structural input files are provided in:

`b2ar/input/`

Reference outputs generated by MUSIKALL are provided in:

`b2ar/output/`

---

## 2. GAPDH

The GAPDH structures were derived from molecular dynamics simulations and were already represented in a common structural reference frame. Therefore, **no additional structural alignment was performed before the MUSIKALL analysis**.

The analysis was performed separately for the **apo** and **restrained (RST)** ensembles.

For each ensemble, inter-chain communication was evaluated for all six pairwise combinations among chains A, B, C, and D:

- **A → B**
- **A → C**
- **A → D**
- **B → C**
- **B → D**
- **C → D**

For every chain pair, residues **150–153** of the first chain were defined as the source and residues **150–153** of the second chain were defined as the sink.

For example:

- **A → B**
  - Source: `A,150-153`
  - Sink: `B,150-153`

- **A → C**
  - Source: `A,150-153`
  - Sink: `C,150-153`

- **A → D**
  - Source: `A,150-153`
  - Sink: `D,150-153`

- **B → C**
  - Source: `B,150-153`
  - Sink: `C,150-153`

- **B → D**
  - Source: `B,150-153`
  - Sink: `D,150-153`

- **C → D**
  - Source: `C,150-153`
  - Sink: `D,150-153`

The same source–sink definitions were applied independently to both the apo and RST ensembles.


The corresponding input structures are provided in:

`gapdh/input/`

Reference outputs generated by MUSIKALL are provided in:

`gapdh/output/`

## 3. 70S Ribosome Complex

The ribosome structures require particular attention to the segment identifiers retained during structural preparation and alignment.

The source residues were defined as:

- **Source:** `EB:C,530,1492,1493`

The sink residues correspond to residues 2451, 2585, and 2602 of chain D. The segment identifier used in the sink definition depends on the ribosome structure selected during alignment.

### DC structure

- **Source:** `EB:C,530,1492,1493`
- **Sink:** `DC:D,2451,2585,2602`

### MC structure

- **Source:** `EB:C,530,1492,1493`
- **Sink:** `MC:D,2451,2585,2602`

Thus, the appropriate segment identifier (`DC` or `MC`) must be used according to the corresponding aligned structure. The segment names `EB`, `DC`, and `MC` refer to the segment identifiers retained in the prepared ribosome structures.

Users should verify the segment identifier in the corresponding PDB file before specifying the source and sink residues in MUSIKALL.

The corresponding ribosome input structures are provided in:

`ribosome/input/`

Reference outputs generated by MUSIKALL are provided in:

`ribosome/output/`

---

## Reproducibility

For each example, the exact structural inputs used in the manuscript and the corresponding reference outputs generated by MUSIKALL are provided in the respective folders. These datasets can be used to verify installation, reproduce the reported analyses, and compare newly generated results with the reference outputs.
